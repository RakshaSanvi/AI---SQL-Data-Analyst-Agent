# AI SQL Data Analyst Agent

## 🚀 Project Overview
This project allows users to upload a CSV file and ask questions in natural language. The system converts the question into SQL queries and provides results with visualizations.

## 🛠 Tech Stack
- Python
- Streamlit
- SQLite
- Groq LLM
- Plotly

## ▶️ How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
